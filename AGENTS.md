# Project instructions

## GitHub uploads

The user has requested that future app changes be uploaded to the existing
GitHub repository `kjak0407/lunachi_app` after implementation and appropriate
verification. This authorization persists across chats in this project.

- Use the existing `origin`: `https://github.com/kjak0407/lunachi_app.git`.
- Commit the changes belonging to the requested app update and push them to
  `main`, unless the user requests a different branch or workflow.
- Check the working tree and remote state first; preserve unrelated user work.
  Never force-push or overwrite remote changes.
- Do not upload credentials, local caches, or temporary files.
- Report whether the upload succeeded, and identify any concrete blocker.
- GitHub Pages may deploy app changes automatically; inspect the existing
  workflow when reporting deployment. Do not claim deployment from a push alone.

This instruction concerns future app updates. Adding this instruction alone
does not require an immediate upload of previously completed work.
