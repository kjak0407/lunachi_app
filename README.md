# ちいさな あそびば

１〜２歳向けの、音と動きを楽しむ９種類のブラウザゲームです。

## 開く

このフォルダーで `node server.mjs` を実行して、http://localhost:5173 を開きます。追加のインストールは不要です。

スマホで試す場合は、PCとスマホを同じWi-Fiに接続し、スマホのブラウザで `http://<PCのローカルIPアドレス>:5173` を開きます。PC側でプライベートネットワークの接続許可が必要になる場合があります。

音声ファイルを読み込むため、上記のサーバー経由で開いてください。

## 今回の内容

- パステル色のホーム画面。３列×３行、１ページ最大９個。
- 「どうぶつのおしゃべり」：犬・猫・牛・ひよこ・ぶた・ひつじ。
- 動物たちは草原をゆっくり歩きます。タップすると立ち止まり、実際の鳴き声とともにジャンプします。ふきだしとハート・音符も現れます。
- 鳴き声は実際の動物の録音です。短く切り出し、無音の調整・音量調整・低域の雑音の除去・端のフェード処理をしてWAV形式で保存しています。音声の出典とライセンスは `dist/credits.html` に記載しています。
- 連打時は前の音を短くフェードさせて切り替え、大量に重なりません。
- ゲーム中の音ボタンでミュート。ホームの歯車を約0.85秒長押しで音量設定。
- 音の設定は端末内に保存します。保存できない場合もその場で使えます。
- トップ画面＋９つのゲームには、それぞれ異なるオリジナルBGM（計10曲）があります。156〜176 BPMのパレード風の曲に、ラッパ風の明るいメロディー、跳ねるベース、はっきりしたドラムと手拍子を組み合わせています。BGMの存在感を上げ、タップの効果音・動物の鳴き声が鳴る間はBGMを一時的に下げます。
- 最初のタップ、またはトップの「おんがくを はじめる」で再生が始まります。画面を切り替えるとBGMもフェードして切り替わります。
- 保護者向け設定でBGMだけのオン・オフと音量を調整できます。ゲーム中のミュートはBGMと効果音の両方を止めます。別のタブへの移動・バックグラウンド化でも止まり、戻ると再開します。
- 「ぽんぽんピアノ」：７色の鍵盤をタップ・なぞって演奏。音符が飛び出します。
- 「ぷかぷかふうせん」：14個の風船が下から次々に浮かびます。割ると音とともに星・お菓子・果物・虹が出てきます。
- 「のりものブーブー」：車・電車・船がそれぞれの音を鳴らして走ります。
- 「わくわく がっき」：たいこ・タンバリン・マラカス・木琴・トライアングル・シンバル・鈴・ギター・ラッパの９種類。各楽器の合成音と、弾む・振れる動きを楽しめます。木琴とラッパはタップごとに音程が変わります。
- 「きらきらおえかき」：６色のペンと６種類のスタンプ。スタンプは指でなぞって並べることもできます。「けす」で消せます。ホームに戻っても絵は残り、ページの再読み込みで消えます。
- 「いないいないばあ」：箱・茂み・プレゼント・花の９か所をタップすると、６種類の動物とうさぎが登場。動物は本物の鳴き声、うさぎは効果音です。もう一度タップすると隠れます。
- 「くだものどうぞ」：いちご・りんご・バナナ・みかん・ぶどう・ももをタップすると、女の子が「あーん」と口を開け、果物が口に飛んでいきます。もぐもぐして笑顔になります。
- 「おみずちゃぷちゃぷ」：指を動かすと水音と波紋。アヒル・魚・かめ・たこ・あざらし・くじら・ペンギン・かにが浮かび、タップすると跳ねたり揺れたりします。
- 動物以外の楽器・効果音は端末内で生成します。連打しても同時に鳴る音は最大８つで、ミュート・ホームへの移動・バックグラウンド化で止まります。
- ゲームの追加時はホームが９個ごとのページに分かれ、左右のスワイプで移動できます。
- 外部通信・広告・ログイン・課金はありません。

## イラスト

BGMは `scripts/prepare-bgm.py` で作曲・音声合成し、`dist/assets/bgm/` に保存したローカルWAVです。外部の音楽素材は使っていません。画面切り替え・高速な連続移動・ミュート・背景での停止の検証は `node --test --test-isolation=none tests/music.test.mjs` で実行できます。

`dist/assets/animals.png` は組み込みImageGenで生成した、1536×1024の透過PNGです。３列×２行の各512×512セルを使っています。

生成プロンプト：丸いパステル色の赤ちゃん動物６匹を等間隔の３列×２行で配置。上段は犬・猫・牛、下段はひよこ・ぶた・ひつじ。大きな頭、小さな手足、丸い目、ほっぺに淡い赤み。絵本風のやさしい統一感。文字・小物・枠なし、背景は透明。

`dist/assets/meadow.png` は組み込みImageGenで１回生成した1024×1536の草原背景です。生成プロンプト：パステル色の絵本風の縦長の草原。上部15%に淡い青空と柔らかい雲、下部85%は淡い緑の広い草地。花と小さな木は端に配置し、中央は動物を置けるよう空ける。動物・人物・文字・UIなし。

`dist/assets/playthings.png` は組み込みImageGenで生成した16種類の透過イラストです。生成プロンプト：丸くかわいいパステル色の玩具とキャラクターを４列×４行の透明な背景に配置。上からピアノ・風船・車・電車、船・太鼓・クレヨン・うさぎ、茂み・箱・いちご・りんご、バナナ・アヒル・魚・水滴。やさしい絵本風、小さな目と笑顔、文字なし。元画像は1254×1254。`scripts/prepare-playthings.py` で切り出し、余白付きの1280×1280アトラスに整えています。

追加イラスト `dist/assets/variety.png` も組み込みImageGenで生成しています。プロンプト：透明背景の４列×４行、丸いパステル色の絵本・粘土玩具風。１行目は同じ女の子の笑顔・あーん・もぐもぐとみかん、２行目はぶどう・もも・かめ・たこ、３行目はあざらし・くじら・ペンギン・かに、４行目はプレゼント・花鉢・あめ・星形クッキー。各セルに余白、文字なし。`scripts/prepare-variety.py` で1280×1280に整えています。

## 確認範囲

トップ画面右上の設定を長押しすると、効果音とBGMを別々に0〜100%で調整できます。効果音は専用の出力を使い、0%でもBGMを止めません。変更は端末のブラウザ内に自動保存され、同じサイトを次に開いた際に復元されます。ブラウザやサイトの保存データを削除すると設定もリセットされます。

乗り物は９種類（車・電車・船・飛行機・バス・ヘリコプター・消防車・救急車・パトカー）。３台ずつ表示し、左右の矢印でページを切り替えます。追加イラストは `dist/vehicles.js` のSVGです。飛行機・バス・ヘリコプターはCC0録音、緊急車両３種はオリジナルの合成サイレンを使っています。

のりものゲームは車の加速音、蒸気機関車の汽笛＋走行音、船の汽笛＋水音のWAVを使用しています。音源・作者・CC0ライセンスは `dist/credits.html` に記載。`scripts/prepare-vehicle-audio.py` で原音から約2.6〜2.8秒の効果音を作成しています。タップで走り出し、再タップ・画面移動・ミュートで前の音を停止します。

ブラウザによって音を出すために初回タップが必要です。実機のSafariでの音量や鳴き声の聞こえ方は、実際に端末で確認してください。
